# D&R Soluções — Landing page

Landing page da D&R Soluções (instalação de câmeras CFTV e monitoramento), feita com Next.js, Tailwind CSS e shadcn/ui.

## Rodar localmente

```bash
npm install --ignore-scripts
npm run dev
```

## Onde alterar os dados da empresa

Nome, slogan, número de WhatsApp e itens do menu ficam em `lib/site.ts`.
O domínio do site vem da variável de ambiente `NEXT_PUBLIC_SITE_URL`.
